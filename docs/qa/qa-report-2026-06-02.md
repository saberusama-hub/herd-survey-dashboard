## Puppeteer harness improvements (Round 4 patch)

Applied to `scripts/qa/{probe_pages,axe_audit,check_links}.js`:

```js
const browser = await puppeteer.launch({
  executablePath: CHROME,
  headless: 'new',
  // macOS sandbox can deadlock under curly-apostrophe `Documents - Usama's MacBook Pro/` path
  args: ['--no-sandbox', '--disable-dev-shm-usage', '--disable-gpu', '--disable-setuid-sandbox'],
});
// ...
await page.goto(`${BASE}${route}`, {
  // DuckDB-WASM streams parquets continuously after page load
  // → network never goes idle → networkidle0 waits forever
  waitUntil: 'domcontentloaded',
  timeout: 45000,
});
```

Pre-patch: probe hung indefinitely at first `page.goto`. Post-patch: 44/44 screenshots captured in ~2 minutes. The remaining Chrome-cleanup hang at `browser.close()` is a separate puppeteer-core/macOS issue that does not affect probe correctness; either add `browser.close().catch(() => process.exit(0))` or have the orchestrator kill the bash subprocess after a grace period.
