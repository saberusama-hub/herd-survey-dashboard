## Dim 3 — Link integrity — PASS

24 unique internal links crawled across 7 root routes; all HTML links resolve, all `.parquet` binary assets return HTTP 200 on HEAD-check.

Round 7 fix: the crawler previously emitted 15 false-positive failures because `puppeteer page.goto()` errors on `ERR_ABORTED` when the response isn't HTML (parquets are binary streamed by DuckDB-WASM). Patched `check_links.js` to detect binary asset URLs (`\.(parquet|csv|json|zip|tar|gz|png|jpg|svg|ico|woff2?)`) and HEAD-check them instead of `goto()`. Result is now a clean PASS.
